# 薪资计算器

按月薪和年终奖月数估算全年薪酬、税后现金、首年条件与期权归属

在线使用：[薪资计算器](https://mx-pai.cn/salary-calculator/)

[计算说明与常见问题](https://mx-pai.cn/salary-calculator/guide/) · [搜索收录配置](SEO.md)

## 本地使用

运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000`，也可使用下方命令生成包含图片与字体的离线单文件

默认按“几个月工资”填写年终奖，修改月薪时奖金金额自动更新，也可切换为直接填金额。固定发薪月数包括约定的 13 薪，年终奖填写额外的预计发放部分

固定发薪月数可快捷选择 12～16 薪。输入框右侧支持加减微调：月薪与奖金金额每次 1,000 元，发薪月数与年终奖月数每次 1 个月；也可直接输入小数月数，减至 0 后减号停用

输入保存在当前浏览器。旧版本保存的奖金总额会迁移为金额模式，原值保留

## 文件结构

| 文件 | 职责 |
|---|---|
| `index.html`、`styles.css` | 页面语义、布局与视觉 |
| `calculator.js` | 配置迁移、校验和纯薪酬计算，不读取 DOM |
| `report.js` | 生成统一报告，提供页面与导出所用的金额、口径和说明 |
| `app.js` | 表单交互、本地保存、结果渲染与复制下载操作 |
| `result-image.js` | 将报告绘制成和纸或热敏工资条，导出纯纸张 PNG |

依赖顺序由 HTML 底部的脚本顺序声明，页面使用普通静态脚本，无需框架或构建依赖

运行计算回归检查：

```bash
node --test tests/calculator.test.cjs
```

生成包含脚本、样式与字体的离线单文件：

```bash
python3 scripts/build-standalone.py ../outputs/salary-calculator.html
```

## 纸张与分享

输入区将月薪、发薪月数和奖金集中排列，并直接显示年收入换算。右侧默认显示全年关键结果，收入与首年明细按需展开；手机输入区同时显示税后月均到手

生成按钮旁可选择和纸或热敏风格，点击“生成工资条”沿用当前风格打开完整工资条，再复制图片或保存 PNG

分享窗口保留打开时的薪酬与纸张快照，预览、复制和保存使用同一张图片。按 Escape 或“关闭”返回计算器

纸纹与撕边在页面和图片中本地绘制，导出内容为纸张、文字与固定落款“一薪一意”，寓意认真对待每一份收入

## 计算口径

“税后月均到手”将固定薪酬和现金补贴摊到每月，不包含年终奖和股权；“含年终奖年均到手”将年终奖计入后再摊到每月，两项均为年度口径估算

税额按居民个人年度综合所得计算。基本减除费用为 6 万元/年，专项附加扣除按全年计；首年社保、公积金按在职月份计，试用期工资差额仅影响首年。计算首年时，固定薪资、年终奖和补贴按在职月数折算，签字费按填写金额计入。模型未合并其他雇主的当年收入

勾选常见缴费参数后，空白基数按月薪、社保个人比例按 10.5%、公积金按 7%，填写的项目优先。基数上下限约束自动推算的基数，手填基数优先；反向上下限会标记错误并暂停税后估算

期权按线性归属加首期等待期计算，估值不代表可变现收入，未计流动性折价及离职失效条款

## 每月累计个税

切换“每月到手”，可按月份查看工资与补贴、年终奖、个人社保与公积金、本月个税、累计个税及预计到手，也可展开累计应纳税所得额、预扣率、速算扣除数和此前已预扣税额的计算过程

月度视图以 1 月起全年在职为前提，不计首年试用期差额和签字费；年度补贴与专项附加扣除均摊到 12 个月，12 薪以上的固定多薪在选择的月份集中发放，不足 12 薪的固定工资按全年金额均摊。奖金默认在 12 月发放，可调整发放月份，计税方式沿用年度方案

预扣税款按分四舍五入，累计减除费用为 5,000 元乘以在职月份。累计应预扣额减去此前已扣税款后，正值在本月扣缴，负值不在当月退款；存在多扣时显示预计汇算退税金额。页面“累计个税”包括综合所得累计预扣与已经发放的单独计税奖金税额，月度到账与年度汇算后金额有各自口径

规则来源：[税务总局累计预扣规定](https://www.chinatax.gov.cn/chinatax/n810341/n810765/n3359382/201812/c4182700/content.html)、[全年一次性奖金政策延续至 2027 年底](https://www.mof.gov.cn/jrttts/202308/t20230828_3904461.htm)

## 隐私与字体

薪资计算、图片生成和数据保存均在浏览器本地完成，无分析脚本、广告或后端接口

页面与和纸工资条优先使用系统中文字体：macOS、iOS 使用苹方，Windows 使用微软雅黑，其余环境回退到自托管的 Noto Sans SC 子集。普通数字与中文使用同一字体，金额采用等宽数字特性；热敏工资条的金额使用系统等宽字体

修改文案后，应将 HTML 和各 JS 中的界面文字加入字符集，重新用 `pyftsubset` 从原字体生成 Noto Sans SC 子集，并重新打包离线文件
